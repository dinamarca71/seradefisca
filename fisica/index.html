Simuladors de Física — 2n de Batxillerat

Col·lecció de simuladors interactius per estudiar ones, oscil·lacions, electromagnetisme i física moderna. Cada pack connecta fórmules, gràfics i fenòmens físics de forma visual i clara.

Com usar els simuladors

Tria un pack temàtic, obre el simulador i experimenta amb els paràmetres. Cada activitat inclou escenaris preparats, valors calculats automàticament i una secció de conceptes clau per treballar a l'aula o de forma autònoma.
