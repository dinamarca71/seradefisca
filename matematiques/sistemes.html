Sistemes d'Equacions Lineals

Resol sistemes quadrats (fins a 4×4) pel mètode de Cramer i discuteix-los amb el teorema de Rouché–Frobenius. Pots incloure un paràmetre m per fer la discussió segons els seus valors.

Fórmules de referència

xᵢ = det(Aᵢ) / det(A)  ·  rang(A) vs rang(A|b)

Rouché–Frobenius (n incògnites): si rang(A) = rang(A|b) = n → SCD (solució única); si rang(A) = rang(A|b) < n → SCI (infinites solucions); si rang(A) ≠ rang(A|b) → SI (sense solució).

Sistema

Incògnites

Pots escriure expressions amb m a les caselles: p. ex. m, 2m, m+1, 1-m, m^2. Usa el punt per als decimals i la barra per a fraccions (1/2).

Resultat

Introdueix els coeficients i el terme independent de cada equació i prem «Resol / Discuteix».

Conceptes clau

  • Regla de Cramer: per a sistemes quadrats amb det(A) ≠ 0, cada incògnita és xᵢ = det(Aᵢ)/det(A), on Aᵢ és A amb la columna i substituïda pels termes independents.
  • Rang: nombre de files (o columnes) linealment independents; s'obté per reducció de Gauss.
  • Teorema de Rouché–Frobenius: compara el rang de la matriu de coeficients amb el de la matriu ampliada per classificar el sistema.
  • Discussió amb paràmetre: es busquen els valors de m que anul·len det(A); per a la resta, el sistema és SCD. En els valors crítics es tornen a comparar els rangs.
  • SCD / SCI / SI: compatible determinat (una solució), compatible indeterminat (infinites) o incompatible (cap).
